# Documentation archive

This index keeps completed, superseded, and dated investigation material
discoverable without presenting it as current setup or backlog. The source files
remain at their original paths where existing evidence links depend on them;
their status headers and this index are the archive boundary. Git history is the
recovery path for removed executable implementations.

## Superseded proposals and experiments

The OpenClaw delegation, native-principal/patch, consent, ACP/AG-UI, Omnigent,
container, and old multi-turn plans are historical design or feasibility
material. They explain why the current boundaries exist; they are not supported
installation instructions or commitments to implement their proposals. The
[OpenClaw delegation spike](../plan/openclaw-delegation-spike/README.md) is
archived feasibility evidence. See the [documentation index](../README.md) for
the current sources of truth.

## Evidence boundary

Historical test and review records retain the exact date and dependency context
under which they were produced. They do not become proof of current provider,
subscription, ingress, or mobile behavior merely by remaining in the tree.
