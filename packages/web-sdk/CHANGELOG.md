# Changelog

## 0.0.10

- Make the package root the entire experimental ACP API.
- Remove the ACP subpath, previous authorization/model clients, generic session
  API and duplicate headless chat presenter without compatibility exports.
- Keep pairing, resumable ACP delivery, fixed WebMCP snapshots, CSP-safe tool
  validation and the AI SDK chat transport.
- Execute application tools internally in the ACP transport; retain stable
  action IDs, cooperative cancellation and explicit recovery without replay.
- Version independently from the gateway and remain on 0.0.x while the shape
  is being finalized. Previous releases remain available in npm and Git history.
