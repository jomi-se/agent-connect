Authorization is explicit. Connectivity alone is not consent.

          

            The browser pins the connector key before disclosing tool schemas.
            The connector shows the exact app origin and tools before issuing a
            revocable PKCE-bound grant. Authentication still does not make an
            application trustworthy; consent must say what a malicious app could
            do.
          

        

      


      

        

          

            
The integration

            
The application stays small.

          

          

            The app declares what the agent may ask for. The connector handles
            how that task reaches a user-owned runtime.
          

        


        

          

            

              

                Web application
                Declare and connect
              

              
            

            
const setPageMessage = defineTool({
  name: "set_page_message",
  inputSchema: {
    type: "object",
    properties: { message: { type: "string" } },
    required: ["message"]
  },
  execute: ({ message }) => {
    pageMessage.textContent = message
  }
})

const agent = await connectAgent({
  runtimeCard,
  tools: [setPageMessage]
})

npm run build --workspace @agent-connect/gateway
